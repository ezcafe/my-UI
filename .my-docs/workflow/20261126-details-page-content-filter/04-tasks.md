Each task follows TDD: write/update the failing test first, verify it fails for the expected reason, implement the minimal change, and re-run workspace tests + clippy + fmt.

## Implementation Tasks

1. **Plain-text summary/excerpt helper (`crates/ui-components/src/sanitizer.rs`):**
   - **Behavior:**
     - Add `extract_plain_summary(summary_html: &str, content_html: &str) -> String`.
     - Before invoking `ammonia`, insert `" "` across block/line-break HTML boundaries (`<br>`, `<br/>`, `</p>`, `<p...>`, `</div>`, `</li>`, `</blockquote>`, `</tr>`, `</td>`, `</th>`, `</h1..h6>`, `</section>`, `</article>`) using a `LazyLock<Regex>` while keeping `<script>` and `<style>` tags untouched so `ammonia` removes their full contents.
     - Strip all remaining tags via `ammonia::Builder::default().tags(HashSet::new()).clean(...)`, decode common entities (`&nbsp;`, `&quot;`, `&#34;`, `&apos;`, `&#39;`, `&#x27;`, `&lt;`, `&gt;`, and `&amp;` **last**), and collapse whitespace.
     - Perform all length truncation (400-char summary cap / 2–3 sentences up to 300-char `content_html` excerpt cap) strictly via `.chars()` / `.char_indices()` (never byte slicing) so multi-byte UTF-8 text (e.g., Vietnamese `"ngụy biện"`, em-dashes) never panics.
   - **Files allowed:** `crates/ui-components/src/sanitizer.rs`
   - **Done evidence:** Unit tests confirm block-tag spacing (`<p>First.</p><p>Second.</p>` -> `"First. Second."`), HTML/script stripping, single-pass entity decoding, UTF-8 multi-byte safety, and brief excerpt cap only.
